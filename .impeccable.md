## Design Context

- **Audience:** People who repeat office and browser work but do not know how to direct an AI agent precisely. They work alongside a browser agent and remain responsible for approvals.
- **Primary job:** Turn a useful result into a typed, repeatable applet; run it with new inputs; inspect its evidence; correct it; publish a better version.
- **First action:** See the durable applet ledger and ask the browser agent to create or run one. The page must make the registered WebMCP tools and their effects legible without becoming a chat interface.
- **Behavioral guardrail:** The external agent proposes and executes bounded operations. EEVEE owns validation, persistence, sandboxing, evaluation, and human approval gates.
- **Personality:** Quiet, exact, and workmanlike. It should feel like a registry and a well-used drafting bench, not an AI dashboard or a startup landing page.
- **Visual direction:** A light, material ledger surface with dense but calm typography, a restrained pine-and-vermilion palette, and a live specimen area. Avoid cards everywhere, decorative gradients, glow, generic icon tiles, fake product windows, and ornamental technical styling.
- **Accessibility:** WCAG 2.2 AA, visible keyboard focus, semantic forms, reduced-motion support, no information conveyed by color alone, and responsive use down to 390px.
